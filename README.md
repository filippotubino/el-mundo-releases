# El Mundo — build Windows

Scarica il gioco dagli **asset della [Release più recente](https://github.com/filippotubino/el-mundo-releases/releases)**, senza account GitHub. Estrai tutti i file dello ZIP e apri **AVVIA.cmd**. Il pulsante “Source code (zip)” non contiene il gioco.

## Anteprima multiplayer 0.1.0

Fino a quattro giocatori, incluso chi ospita sul proprio PC. Crea una partita privata/pubblica, comunica il codice oppure usa l'elenco pubblico. Cooperativa contro cinque guardiani e duelli a round; movimento, combattimento e salute realmente condivisi. Chi ospita deve restare connesso: la sua uscita termina la partita.

Online: spada e scudo fissi, attacco normale/forte, parry, schivata, salto, sprint e tre pozioni. Magie, altre armi, combo complete, inventario, personalizzazione, missioni e premi rimangono nella modalità offline completa.

Windows 64 bit. Nessun account Unity o carta di credito richiesti ai giocatori. Unity Relay/elenco sono configurati entro quote gratuite senza fatturazione: le quote non sono illimitate e il loro superamento può bloccare il multiplayer Internet. Offline e LAN restano disponibili. Nessun server dedicato affittato.

Quattro processi Windows verificati realmente via Relay sullo stesso PC, con codice/elenco, battaglia, ingresso tardivo e chiusura dell'host. Prove tra PC/reti diversi, controller fisici e latenza/perdita pacchetti ancora da completare. Il programma non è firmato digitalmente: Windows può mostrare SmartScreen. Consultare **LEGGIMI.md** nello ZIP per avvio, comandi e limiti; crediti in **Licenses**.

Questo repository distribuisce build e istruzioni, non il progetto Unity.
